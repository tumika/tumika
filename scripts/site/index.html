tumika

This host serves tumika's installer and the signed bills of materials its daemons read to find an update. Everything here is generated from the published GitHub releases; nothing is edited by hand.

Install the daemon

curl -fsSL https://get.tumika.org/install-daemon.sh | sh

What is published

  • /channels/<channel>.json — the head of a channel: stable, beta or edge.
  • /releases/<label>.json — one release's components and their assets.
  • <document>.json.sig — the detached ECDSA P-256 signature beside every document. A daemon refuses a document that does not verify against a key compiled into it.

Source and releases: github.com/tumika/tumika.
